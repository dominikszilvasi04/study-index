# StudyIndex Context

This tracked directory contains working context for agents, contributors and the project owner.

## Reading Order

1. `STATUS.md` for the current repository state and immediate next action.
2. `DECISIONS.md` for decisions that affect implementation.
3. `CONVENTIONS.md` before writing or reviewing code.
4. `DESIGN.md` when work affects product behaviour, architecture, data or delivery.

## Maintenance

- Update `STATUS.md` after material work or when the next action changes.
- Add durable decisions and their reasoning to `DECISIONS.md`.
- Update `CONVENTIONS.md` when the owner changes a project-wide working preference.
- Update `DESIGN.md` when product scope or architecture changes.
- Record enough information for a future agent to resume without reconstructing earlier discussions.
- Do not copy raw command logs or large sections of source code into these files.
